# Weekly Electricity Consumption Matrix

## About the Project
The Weekly Electricity Consumption Matrix system is a Python-based program that calculates electricity consumption for different household appliances over seven days.

## Objectives
- Store appliance-wise daily electricity readings.
- Calculate weekly consumption for each appliance.
- Calculate total daily consumption.
- Compare electricity usage across different days.

## Concepts Used
- Variables and data types
- Lists
- Nested lists
- For loops
- Arithmetic operators

## How the Program Works
1. The program defines three household appliances.
2. Daily electricity consumption values are entered for seven days.
3. The readings are stored in a nested list.
4. Weekly consumption is calculated for each appliance.
5. Total electricity consumption for each day is calculated.
6. The electricity consumption report is displayed.

## Conclusion
This project demonstrates how nested lists and loops can be used to organize and analyse household electricity consumption.
